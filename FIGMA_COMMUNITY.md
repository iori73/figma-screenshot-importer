# Figma Community Publishing Checklist

- [ ] **Icon** (128x128): Plugin icon for the listing
- [ ] **Description**: See below
- [ ] **Category Tags**: `Design Tools`, `Productivity`, `Screenshots`, `Research`

## Description (English)

**Bulk Screenshot Importer** organizes your screenshots into Figma with two powerful modes:

**Folder Import** — preserves your local folder structure, converting it into Figma's Section/AutoLayout hierarchy. Perfect for website benchmarking and design research libraries.

**Smart Import** — automatically analyzes smartphone app screenshots to detect scroll sequences and section breaks. Just select your screenshots — the plugin sorts by filename, detects when consecutive captures are from the same scrollable screen, and groups them by app tab/section. Edit section names, adjust detection sensitivity, and import with one click.

Features:
• High-resolution support with automatic image chunking
• Preview before import
• Cancel support for long imports
• Configurable image width and sensitivity sliders

## Description (日本語)

**Bulk Screenshot Importer** は、スクリーンショットをFigmaに効率的にインポートするプラグインです。

**Folder Import** — ローカルのフォルダ構造をFigmaのSection/AutoLayout階層に変換。Webサイトの競合分析やデザインリサーチに最適。

**Smart Import** — スマートフォンアプリのスクリーンショットを自動解析。スクロール画面の自動連結、アプリのタブ/セクションごとの自動グループ化。ファイル名で自動ソート、セクション名の編集、感度調整が可能。

機能:
• 高解像度画像の自動分割対応
• インポート前のプレビュー
• キャンセル機能
• 画像幅・検出感度の調整

## Publishing Steps

1. Go to https://www.figma.com/community
2. Click "Publish a plugin"
3. Upload the cover image and icon
4. Paste the description
5. Select appropriate category tags
6. Submit for review
