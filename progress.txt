# Bulk Screenshot Importer - Progress

## v2.1.0 (2026-02-27) - AI Section Naming & UX Improvements

### 完了
- [x] Gemini AI セクション名提案機能

  - 各セクションの代表サムネイルを1回のAPI呼び出しで送信
  - APIキーは localStorage に保存、Settings UI で入力
  - エラー時はファイル名ベースのサジェストにフォールバック
  - manifest.json に generativelanguage.googleapis.com を許可追加
- [x] ファイル名ベースのセクション名サジェスト
  - 20カテゴリのキーワード辞書（Home, Login, Search, Profile 等）
  - ファイル名に共通する単語を抽出するフォールバック
  - 重複名の回避ロジック
- [x] セクション名ゴーストテキストUI
  - placeholder にサジェスト名を表示（イタリック薄字）
  - Tab/Enter でサジェスト受入
  - 「Tab ↵」ヒントバッジ表示
  - エクスポート時は name || suggestedName || Section N のフォールバック
- [x] スクロール検出の改善
  - stripHasEnoughDetail: ストリップのピクセル分散チェック
  - 単色ストリップ（ダーク系UI等）でのスクロール誤検出を防止
- [x] UI/UX 改善
  - 各タブに説明文追加（Folder Import / Smart Import の違いを明示）
  - 言語切替をセグメントコントロール（EN/JA）に変更
  - APIキー入力欄追加（目のSVGアイコン、表示切替）
  - ヒントテキスト更新（AIキーの役割と無しの場合の説明）
  - Image Width デフォルト値を 390px に変更
- [x] 本番公開準備 v2
  - manifest.json の networkAccess 修正（Gemini API許可）
  - code.js の minify 有効化（約8KB → 約4.5KB）
  - プロジェクトドキュメント更新（CLAUDE.md, progress.txt, lessons.md）
